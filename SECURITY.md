# Security Policy

## Reporting a vulnerability

Please report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/honestarcade/HonestFrogAcross/security/advisories/new) — **not** a public issue. A public reproduction is a working exploit handed to everyone before a fix exists.

This is a small independent project: reports are handled on a best-effort basis, with no guaranteed response timeline. You'll hear back as soon as the maintainer can get to it.

## How findings are tracked

Security findings from the project's own audits are tracked as public GitHub issues under the `security` label, with `sev:*` severity labels. Externally reported vulnerabilities stay private (as advisories) until a fix is available.
